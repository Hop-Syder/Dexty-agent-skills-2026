# Frontend UI Engineering

## Overview
Construct performant UI components using modular design tokens, semantic HTML, robust accessibility (WCAG), and responsive CSS/Tailwind layouts.

## Workflow
1. Align with design tokens (colors, spacing, typography).
2. Implement accessible interactive elements (keyboard navigation, ARIA).
3. Optimize re-renders and client bundle sizes.
