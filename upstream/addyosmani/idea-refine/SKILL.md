# Idea Refine

## Overview
Transform an unstructured idea or vague product request into a scoped, testable initiative. Clarify target audience, core problem, success metrics, and non-goals.

## Workflow
1. Extract the core user pain point.
2. Define the minimal viable scope (cut extraneous features).
3. Identify technical constraints and operational dependencies.
4. Deliver an idea brief ready for `spec-driven-development`.
