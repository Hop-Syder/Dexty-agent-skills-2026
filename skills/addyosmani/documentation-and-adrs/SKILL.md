# Documentation and ADRs

## Overview
Document significant architectural decisions using standard Architecture Decision Records (ADR: Context, Decision, Consequences) to preserve project rationale.

## Workflow
1. Identify architectural inflection points (framework choice, data store, auth strategy).
2. Author ADR document with clear pros/cons.
3. Archive in `docs/adr/`.
