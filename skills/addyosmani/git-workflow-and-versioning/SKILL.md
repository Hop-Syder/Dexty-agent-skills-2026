# Git Workflow and Versioning

## Overview
Maintain atomic Git commits, meaningful conventional commit messages, branch hygiene, and semantic release tagging.

## Workflow
1. Use isolated branches or worktrees for distinct tasks.
2. Commit with conventional format (`feat:`, `fix:`, `refactor:`).
3. Tag releases using SemVer (`vX.Y.Z`).
