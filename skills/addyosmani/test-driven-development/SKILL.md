# Test-Driven Development (TDD)

## Overview
Follow the strict Red-Green-Refactor discipline: write a failing test first, write minimal code to pass, then refactor cleanly.

## Workflow
1. **Red**: Write a focused unit or integration test that fails.
2. **Green**: Write the simplest code that makes the test pass.
3. **Refactor**: Clean up duplication, improve readability, and keep tests green.
