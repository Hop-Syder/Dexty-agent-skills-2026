# Source-Driven Development

## Overview
Respect the existing codebase. Never introduce redundant utilities or conflicting design patterns when established idioms already exist in the repository.

## Workflow
1. Search codebase for existing helper functions and patterns.
2. Reuse existing dependencies before installing new packages.
3. Match formatting, naming conventions, and project idiom.
