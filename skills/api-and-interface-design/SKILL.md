# Api And Interface Design

## Objectif opérationnel
Concevoir des API REST ou GraphQL claires et cohérentes. Ce skill encadre l'intervention de l'agent `workflow-ux-owner` avec des règles vérifiables avant toute validation.

## Protocole d'exécution
1. Analyser le contexte dans `.project-memory/MAP.md`, `REFUSALS.md` et `ERRORS.md` avant d'agir.
2. Appliquer les contrôles de qualité et de sûreté propres au domaine (api, rest, graphql, design, interface).
3. Produire un livrable testable, sans secret en dur ni dépendance non vérifiée.
4. Documenter les arbitrages techniques pour revue par l'agent QA / Evaluator.
