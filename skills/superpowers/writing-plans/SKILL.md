# Writing Plans

## Overview
Author explicit, verifiable implementation plans that provide all necessary context so an autonomous sub-agent can execute without guessing.

## Structure
- Objective and scope.
- Prerequisite files and tools.
- Granular numbered steps with explicit verification commands.
- Checkpoints where human or review sign-off is required.
